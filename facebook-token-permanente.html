Token Page permanente

Per Crypto Italia Facile — token che non scade.

Metodo 1 — Access Token Tool (consigliato, 2 minuti)

  1. Apri Access Token Tool (loggato come admin app).
  2. Trova l'app CryptoFacile Poster e il token User.
  3. Clicca Extend Access Token sul token User.
  4. Nella sezione Page Access Tokens copia il token di Crypto Italia Facile.
  5. Verifica che la scadenza sia Never / mai.
  6. Esegui: 
    python scripts\aggiorna-token-facebook.py INCOLLA_TOKEN_PAGINA

Usa il token della Pagina, non quello User.

Apri Access Token Tool

Metodo 2 — Script automatico (serve App Secret)

  1. App Secret: Impostazioni app → Basic
  2. Token USER dal Graph API Explorer
  3. Aggiungi in scripts/.env: FACEBOOK_APP_SECRET=...
  4. Esegui: 
    python scripts\token-permanente.py EAA...

Verifica

python scripts\verify-facebook-token.py

Deve comparire: Scade: (token pagina — di solito non scade)
